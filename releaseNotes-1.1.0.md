# System Transparency 1.1.0

## Highlights

- Added English and Korean UI language support.
- Added `Setting > Language` with System default, English, and Korean options.
- Refined custom hotkey validation so every manual action supports up to 4 modifier keys.

## What Changed Since 1.0.6

- Tray menu labels, dialogs, warning messages, and update status messages can now display in English or Korean.
- The default language follows the Windows UI language when `System default` is selected.
- Language choice is saved in the app registry settings.
- Owner-drawn menus and dialogs now use Unicode text paths for Korean text.

## Download

- `SystemTransparency.exe`: signed single-file app.
- `SystemTransparency.zip`: zipped copy of the signed executable.

## Notes

- First-run setup may require UAC.
- Some protected or GPU-accelerated windows may reject transparency changes.
