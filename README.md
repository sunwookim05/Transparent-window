# 🪟 System Transparency

**System Transparency**는 Windows 환경에서 탐색기 창을 자동으로 반투명 처리하여  
작업 환경을 깔끔하고 모던하게 만들어주는 경량 유틸리티입니다.

## 🛠️ Built With
- **Language:** C (Win32 API)
- **Compiler:** GCC (MinGW)
- **Platform:** Windows 10 / Windows 11 (x64)
- **Installer:** NSIS
- **Type:** Tray-based Desktop Utility

---

## ✨ 주요 기능

### 1️⃣ 자동 투명화
- Windows 탐색기(`CabinetWClass`, `ExploreWClass`) 창 자동 반투명화
- 우클릭 메뉴, 추가 메뉴 등 Windows 11 새로운 메뉴 지원
- 별도 조작 없이 자동으로 적용

### 2️⃣ 사용자 조정 투명화
- **Ctrl + 마우스 휠 클릭** → 현재 활성 창 반투명화
- **Win + 마우스 휠 클릭** → 현재 활성 창 불투명화
- **Ctrl + Win + 마우스 휠** → 창 투명도 단계별 조절

### 3️⃣ 트레이 아이콘
- 시스템 트레이에 상주하며 바로 접근 가능
- 우클릭 메뉴 제공:
  - 프로그램 정보 확인
  - GitHub 페이지 이동
  - 프로그램 종료

### 4️⃣ Windows 11 호환
- 기존 Explorer 창뿐 아니라 새로운 스타일 메뉴에도 투명화 적용
- 자동 투명화 + 수동 조절 기능 동시 지원

---

## ⚙️ 설치 및 실행
1. Releases 페이지에서 `Setup.exe` 다운로드
2. 설치 후 자동 실행 (Windows 시작 프로그램 자동 등록)
3. 트레이 아이콘 표시 후 자동 투명화 적용
4. 필요 시 단축키로 직접 투명도 조절

---

## 🔄 Auto Startup
- 설치 시 Windows 시작 프로그램에 자동 등록
- Windows 로그인 시 자동 실행
- 백그라운드 트레이 앱으로 동작

---

## ⚠️ 주의 사항
- 일부 프로그램(게임, 보안 프로그램, GPU 가속 앱)에서는 투명화가 제한될 수 있습니다
- 기본적으로 Windows 탐색기 및 메뉴에 최적화되어 있으며,
  그 외 창은 수동 조절을 권장합니다
