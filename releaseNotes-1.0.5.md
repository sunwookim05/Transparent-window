# System Transparency 1.0.5

## Highlights

- Added configurable manual transparency hotkeys.
- Added a dark `Setting > Hotkeys...` dialog.
- Added shortcut recording for apply, restore, and opacity-adjust actions.

## What Changed Since 1.0.4

- Manual shortcut modifiers are now saved in the app registry settings.
- Defaults remain compatible with previous releases:
  - `Ctrl + Middle Click`: apply the selected preset.
  - `Win + Middle Click`: restore full opacity.
  - `Ctrl + Win + Mouse Wheel`: adjust opacity step by step.
- The hotkey recorder prevents apply and restore from using the same middle-click shortcut.
- Updated README usage text for configurable hotkeys.

## Download

- `SystemTransparency.exe`: signed single-file app.
- `SystemTransparency.zip`: zipped copy of the signed executable.

## Notes

- First-run setup may require UAC.
- Some protected or GPU-accelerated windows may reject transparency changes.
