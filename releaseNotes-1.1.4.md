# System Transparency 1.1.4

## Highlights

- Turned the Hotkeys and Custom Alpha windows into compact popup-style panels that open near the tray menu.
- Kept the Custom Alpha slider, live numeric value, and live transparency preview while making the flow feel more like part of the right-click menu.
- Added Escape and Enter handling for quicker popup panel dismissal/confirmation.
- Updated README usage notes for the current tray menu and popup panel behavior.

## Notes

- Popup menu transparency remains best effort on Windows 11 because some modern shell menus use composition surfaces that may reject layered-window transparency.
